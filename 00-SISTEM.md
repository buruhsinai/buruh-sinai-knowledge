# BURUH SINAI KNOWLEDGE

## Sistem Kerja Repository

Repository ini digunakan sebagai laboratorium pengetahuan.

Tujuannya bukan sekadar menyimpan tulisan, tetapi menangkap,
menyusun, menghubungkan, menguji, dan mengembangkan gagasan.

---

## 1. Gagasan

Setiap gagasan yang muncul boleh ditangkap terlebih dahulu
tanpa harus langsung menjadi tulisan yang sempurna.

Gagasan dapat berkembang, berubah, digabungkan, atau ditinggalkan.

---

## 2. Pertanyaan

Pertanyaan yang belum terjawab tidak perlu dipaksakan menjadi kesimpulan.

Pertanyaan dapat menjadi titik awal penelitian dan pengembangan gagasan.

---

## 3. Pengetahuan

Gagasan yang telah cukup matang dapat dirumuskan menjadi file pengetahuan.

Satu file sebaiknya memiliki satu fokus utama.

---

## 4. Hubungan

Sebuah gagasan dapat berhubungan dengan banyak gagasan lainnya.

Hubungan tersebut perlu dicatat agar repository berkembang menjadi jaringan
pengetahuan, bukan sekadar kumpulan file.

---

## 5. Sumber

Pernyataan penting harus dapat ditelusuri kepada sumbernya jika memungkinkan.

Bedakan antara:

- fakta
- sumber
- interpretasi
- dugaan
- pertanyaan

---

## 6. Perubahan

Pengetahuan boleh berubah.

Perubahan tidak perlu disembunyikan karena sejarah perubahan merupakan
bagian dari proses berpikir.

Git commit digunakan untuk meninggalkan jejak perkembangan tersebut.

---

## 7. Prinsip Utama

Tangkap → Pisahkan → Hubungkan → Uji → Kembangkan → Jejaki

---

Repository ini tidak dibuat untuk mengejar bentuk akhir sejak awal.

Struktur dapat berkembang mengikuti kebutuhan pengetahuan.
