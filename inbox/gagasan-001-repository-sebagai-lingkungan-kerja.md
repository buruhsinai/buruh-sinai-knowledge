# Repository sebagai Lingkungan Kerja

## Gagasan

Repository mungkin tidak tepat dipahami hanya sebagai tempat
menyimpan atau mengunggah file.

Ia dapat menjadi lingkungan kerja tempat gagasan ditangkap,
diubah, dihubungkan, diuji, dan dilacak perkembangannya.

## Pertanyaan

Sejauh mana sebuah repository GitHub dapat digunakan sebagai
lingkungan kerja pengetahuan tanpa bergantung pada komputer,
upload file dari luar, atau website GitHub?

## Hipotesis

Kemampuan repository tidak hanya terletak pada penyimpanan file.

File, commit, history, branch, issue, pull request, discussion,
dan automation dapat membentuk suatu sistem kerja yang lebih luas.

## Eksperimen

Mulai dari aplikasi GitHub Android.

Tidak mengunggah file dari perangkat luar.

Buat seluruh bahan awal langsung di dalam repository.

Kemudian uji satu per satu kemampuan GitHub yang relevan.

## Catatan

Jangan membatasi rancangan hanya agar cocok dengan aplikasi Android.

Android adalah alat untuk mengakses sistem.

Jika suatu pekerjaan membutuhkan antarmuka lain, gunakan antarmuka
tersebut tanpa mengubah prinsip utama sistem.
