Laboratorium Pengetahuan

Repository ini adalah ruang untuk menangkap, menyusun, menghubungkan, dan mengembangkan gagasan.

Ia bukan website, bukan sekadar tempat menyimpan catatan, dan bukan kumpulan tulisan yang selesai sekali dibuat.

Setiap file adalah satu unit pengetahuan yang dapat berkembang.
Setiap hubungan antarfile membentuk jaringan gagasan.
Setiap perubahan meninggalkan jejak perkembangan pemikiran.

Prinsip

- Tangkap — jangan biarkan gagasan penting hilang.
- Pisahkan — satu gagasan utama menjadi satu unit yang jelas.
- Hubungkan — gagasan tidak berdiri sendiri.
- Uji — bedakan antara fakta, sumber, penafsiran, dugaan, dan pertanyaan.
- Kembangkan — pengetahuan boleh berubah ketika pemahaman bertambah.
- Jejaki — perubahan tidak perlu disembunyikan; sejarah pemikiran adalah bagian dari pengetahuan itu sendiri.

Repository ini dapat berkembang ke berbagai bidang tanpa harus ditentukan seluruhnya sejak awal.

Website, artikel, kajian, penelitian, maupun bentuk publikasi lainnya dapat menjadi keluaran dari pengetahuan yang berkembang di sini, tetapi bukan tujuan utama repository ini.

Satu gagasan → satu jejak → banyak hubungan → pemahaman yang terus berkembang.
